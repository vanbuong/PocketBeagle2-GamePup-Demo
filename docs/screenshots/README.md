# Screenshot provenance

These images were captured from the real GamePup framebuffer on a PocketBeagle
2 running Armbian on July 26, 2026. Each PNG is the native 128x160 RGB LCD
output from the original ST7735R panel, without upscaling or post-processing.
They are kept as historical UI references after the project switched to an
ILI9341 landscape 320x240 framebuffer.

The gallery intentionally contains only original GamePup UI and GPU benchmark
scenes. It contains no ROM imagery, commercial game screenshot, or Doom data.
The screenshots are licensed with the project under GPL-2.0-only.
