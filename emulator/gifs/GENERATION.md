# OLED animation artwork

`bongo-cat.gif` is an original four-frame animation generated with OpenAI's
built-in image-generation tool and then cropped and reduced to 96x96 pixels
with nearest-neighbor scaling.

Prompt summary: create an original white-and-orange pixel-art cat playing two
small bongo drums as four consistent frames in a 2x2 sprite sheet, on a dark
navy background, with alternating raised and lowered paws; no text, logos,
watermarks, or copyrighted character likeness.

`bongo-cat-spritesheet.png` is retained as the editable high-resolution source.
